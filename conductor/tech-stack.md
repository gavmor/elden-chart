# Tech Stack

## Language
- **TypeScript**: Typed superset of JavaScript, providing strong typing and enhanced tooling.

## Frameworks
- **React 19**: Frontend UI library for building component-based interfaces.
- **Vite**: Next-generation, high-performance frontend tooling and bundler.
- **Tailwind CSS v4**: Utility-first CSS framework for rapid UI development and styling.
- **GraphQL**: Used via `graphql-request` and `GraphQL Code Generator` for type-safe data fetching.
- **TanStack React Query v5**: For declarative, cached query state management.
- **Observable Plot**: For imperative data visualization.

## External APIs
- **Deadlock API TypeScript client**: Integrated via `@deadlock-api/openapi-clients` for fetching Deadlock items.

## Database
- **None**: This is a pure frontend Single Page Application (SPA). Data is fetched from an external GraphQL API.
